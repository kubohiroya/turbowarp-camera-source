Camera Source

English日本語

TurboWarp capability extension

カメラストリームを1本にまとめる。

Camera Sourceは`navigator.mediaDevices.getUserMedia()`を一元管理し、TMPoseやjsQRなどの拡張にlease付きでライブフレームを共有します。

start shared camerashared camera is running?stop shared camera

ブロック

start shared camera

カメラ許可を要求し、共有MediaStreamを開始します。

stop shared camera

共有ストリームを停止し、トラックを解放します。

shared camera is running?

共有ストリームが有効かを返します。`shared camera device ID`は利用中のデバイスIDを返します。

API capability

unsandboxed拡張は`Scratch.vm.runtime.ext_kubohiroyacamerasource`を参照できます。

const lease = await cameraSource.acquireCamera({owner: 'my-extension'});
const frame = lease.getFrameSource();
await lease.release();

最後のleaseが解放されるまでストリームは維持されます。

プライバシーと要件

カメラ利用にはユーザー許可とHTTPSまたはlocalhostなどの安全なコンテキストが必要です。Camera Sourceはフレームをアップロードせず、画像も保存しません。
