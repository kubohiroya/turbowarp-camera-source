Camera Source
ブロックAPIプライバシー
English日本語

TurboWarp capability extension

姿勢、画像、QRでカメラを使い分ける。

Camera Sourceは`navigator.mediaDevices.getUserMedia()`を管理し、役割名ごとにライブフレームを共有します。TMPoseは水平カメラ、jsQRや画像認識は下向きカメラ、という構成にできます。

start shared camera posestart shared camera qrcamera device ID at 1

ブロック

start shared camera

カメラ許可を要求し、`pose`や`qr`などの名前付きMediaStreamを開始または維持します。

refresh camera devices

ブラウザのカメラ一覧を更新し、役割名をdevice IDへ割り当てられるようにします。

shared camera is running?

名前付きストリームが有効かを返します。device ID reporterは選択中の物理カメラを返します。

API capability

unsandboxed拡張は`Scratch.vm.runtime.ext_kubohiroyacamerasource`を参照できます。

const poseLease = await cameraSource.acquireCamera({
  owner: 'tmpose',
  cameraId: 'pose',
  deviceId: poseDeviceId
});
const qrLease = await cameraSource.acquireCamera({
  owner: 'jsqr',
  cameraId: 'qr',
  deviceId: qrDeviceId
});
const frame = qrLease.getFrameSource();
await qrLease.release();
await poseLease.release();

各ストリームは最後のleaseが解放されるまで維持されます。同じ`cameraId`なら1つの物理カメラを共有し、異なるIDなら別カメラを同時利用できます。

プライバシーと要件

カメラ利用にはユーザー許可とHTTPSまたはlocalhostなどの安全なコンテキストが必要です。Camera Sourceはフレームをアップロードせず、画像も保存しません。
